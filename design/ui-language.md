# UI language

These rules apply to every Ocalt user interface.

## 1. No imitation window chrome

Never use macOS-style window buttons.

## 2. Views that are not ready

A view that is not yet loaded, or is offline, shows a custom Ocalt or OcaltQL waiting screen or offline screen. It never shows a generic placeholder.

## 3. Labels

- Labels are formal and serious.
- A label is uniform with its neighbours. It follows the wording style of the labels beside it.
- No casual or clever phrasing. Example of what is rejected: "Serve which host".

## 4. Colour scheme

Published Ocalt pages declare both light and dark colour schemes and a theme colour of `#000000`.

## 5. Enforcement

These rules are checked in review. See [../handbook/review.md](../handbook/review.md).
