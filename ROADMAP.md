# Roadmap

Public, org-level only. Per-project detail stays in each project's repository, and what has shipped is recorded at https://ocalt.com/changelog.

## Committed to publish, no date stated

The Security Model page at https://ocalt.com/security lists what Ocalt has not yet published and states that each item will appear on that page and in the changelog when it exists:

- an independent penetration test or security audit;
- a compliance certification such as SOC 2 or ISO 27001;
- a service-level agreement with uptime or response commitments;
- a documented disaster-recovery plan and incident-response procedure;
- a statement on encryption at rest for stored files and databases.

An organisation that needs one of these before adopting Ocalt can say so through https://ocalt.com/support, so Ocalt knows which matters most.
