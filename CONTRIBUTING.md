# Contributing

## Before you start

1. Read [handbook/principles.md](handbook/principles.md). The specification is the source of truth.
2. For anything beyond a correction, open an issue first and state the change you propose.

## Scope of this repository

This repository holds what is true of Ocalt as a whole. OcaltQL projects belong in [`ocaltql`](https://github.com/Ocalt/ocaltql). Research belongs in [`research`](https://github.com/Ocalt/research).

## A pull request

- Contains only what the linked issue asks for.
- Meets the [definition of done](handbook/definition-of-done.md).
- Follows the [conventions](handbook/conventions.md).
- Contains no hostnames, IP addresses, server paths, configuration or credentials.

## Decisions

Cross-cutting decisions are made by record. See [decisions/README.md](decisions/README.md).

## Security

Do not report vulnerabilities through issues. See [SECURITY.md](SECURITY.md).
